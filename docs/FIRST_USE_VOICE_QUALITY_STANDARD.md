# 迴響首次語音克隆品質標準

## 結論

迴響若要讓家屬在首次正式使用時得到可信賴的結果，不能把「任意音檔上傳後立即生成」當作正式服務流程。品質應由**已驗收的原始錄音、逐字正確的參考文字、可重用的正式 Profile，以及簡潔一致的生成設定**共同決定。

Qwen3-TTS Base 的語音克隆介面需要同時提供參考音檔與參考文字；官方也提供建立可重用 `voice_clone_prompt` 的方式，以避免每次重新計算參考特徵並讓同一聲音身份維持一致的條件輸入。[1]

> Qwen3-TTS 技術報告指出，語音克隆可使用參考語音的 speaker embedding，或使用文字—語音配對的 in-context learning；後者較能保留韻律。[2]

## 首次正式使用的品質門檻

| 項目 | 最低可接受 | 建議正式標準 | 不應直接建立正式 Profile 的情況 |
|---|---:|---:|---|
| 單一說話者的連續語音 | 20 秒 | 45–90 秒 | 多人交談、唱歌、廣播、背景音樂主導 |
| 可理解的自然說話比例 | 大於 80% | 大於 95% | 長時間靜音、嚴重回音、電話爆音、背景噪音壓過人聲 |
| 參考文字 | 可由 Whisper Large 產生初稿 | 家屬／服務人員逐字校正後確認 | 只用「嗯」、「測試測試」或未校正的錯誤轉錄 |
| 聲音身份 | 候選 Profile | 三段固定預覽通過後的正式 Profile | 每次生成重新建立 `echo_時間戳` Profile |
| 情緒設定 | 一個主情緒 | 一個主情緒＋一句短補充 | 同時混合激昂、溫柔、開心等互斥描述 |

## 首次體驗的標準流程

### 1. 樣本接收與預檢

系統應先檢查音檔是否接近單一說話者、可辨識、音量穩定且有足夠自然對話。若不符合標準，應顯示「此音檔不適合作為正式聲音樣本」並引導家屬改選片段，而不是直接生成一段低相似語音。

### 2. 參考文字確認

Whisper Large 僅作為初稿。家屬或服務人員必須確認姓名、稱呼、數字、台語／宗教用語與語助詞。Qwen Base 對應文字—語音配對進行克隆，錯誤或過短的參考文字會使咬字與韻律品質失去可靠條件。[1] [2]

### 3. 候選 Profile 與三段預覽

候選 Profile 建立後，不應立刻用於家屬正式文案。應先生成自然對話、情感句與家屬專用詞三段預覽，並由家屬確認「音色相似、讀音正確、情感自然」。只有核可版本可成為正式 Profile。

### 4. 固定正式 Profile

通過核可後，所有正式生成都重用同一個 `voiceProfileId`。官方的可重用 voice clone prompt 概念支持這種「一次建立、重複使用」的品質策略；新增較好錄音時只建立候選版本，不能覆蓋已核可的最佳版本。[1]

## 迴響立即可採用的預設值

| 設定 | 建議值 | 原因 |
|---|---|---|
| 引擎 | Qwen 1.7B Base | 現有流程已驗證其克隆音色能力；採用既有 Profile 可維持一致性 |
| 語言 | `zh` | 明確指定中文，避免自動語言辨識波動 |
| 參考文字 | 手動核對後版本 | 讓音訊與文字配對可用於保留咬字與韻律 |
| 主情緒 | 只選一個 | 避免互斥情緒在單次生成中互相抵銷 |
| 自訂提示 | 20–40 字、只描述當下語氣 | Profile 負責長期口吻，單次提示只負責情境 |
| 罕見字 | 經驗證的同音代理＋家屬詞庫 | 只在 TTS 內部替換，介面與回憶庫保留正字 |

## 自動化優先順序

1. **Profile 重用**：生成頁選擇已核可親友，而非每次建立新 Profile。
2. **品質閘門**：不足 20 秒、多人、噪音過高或未確認參考文字的樣本不可直接用於正式生成。
3. **三段預覽與核可**：把家屬首次聽感驗收放在正式文案之前。
4. **版本回退**：新樣本不會覆蓋既有最佳 Profile；家屬可隨時切回已核可版本。
5. **專屬詞庫**：姓名、稱呼與宗教用語綁定在親友聲音身份，而不是以全域規則混用。
